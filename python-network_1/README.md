# Python Network 1

These exercises use urllib and Requests to fetch response bodies and
headers, submit form data, handle HTTP errors, and read JSON. The scripts
target Python 3.4.3. Scripts 4 through 8 and 10 require Requests.

Run these examples from this directory with the course server on port 5000.

```sh
./2-post_email.py http://127.0.0.1:5000/post_email hr@holbertonschool.com
./7-error_code.py http://127.0.0.1:5000/status_401
./8-json_api.py a
```

# Python - More Classes

This directory contains the solutions for the `python-more_classes` project.

## Tasks

- `0-rectangle.py`: empty `Rectangle` class.
- `1-rectangle.py`: validated width and height properties.
- `2-rectangle.py`: area and perimeter methods.
- `3-rectangle.py`: printable rectangle representation.
- `4-rectangle.py`: evaluable `repr` representation.
- `5-rectangle.py`: deletion message.
- `6-rectangle.py`: instance counter.
- `7-rectangle.py`: configurable print symbol.
- `8-rectangle.py`: compare rectangles by area.
- `9-rectangle.py`: class method to create a square.

# Python Network 0

These Bash scripts use cURL to measure response bodies, follow redirects,
send DELETE requests, read allowed methods, and send headers and form data.

Pass the full URL or a host, port, and path as the first argument.

```bash
./0-body_size.sh http://127.0.0.1:5000/
./1-body.sh http://127.0.0.1:5000/route_1
```

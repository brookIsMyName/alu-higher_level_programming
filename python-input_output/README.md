# Python Input and Output

Exercises in reading and writing UTF-8 files, serializing Python objects as
JSON, restoring objects from JSON, and generating Pascal's triangle.

Files `0` through `2` implement text file operations. Files `3` through `6`
convert JSON strings and files to and from Python objects. Run `7-add_item.py`
with arguments to append them to `add_item.json` in the current directory.
Files `8` through `11` expose instance attributes for serialization and restore
student data. File `12-pascal_triangle.py` builds the requested triangle rows.

All Python scripts target Python 3.8 and use only the standard library.

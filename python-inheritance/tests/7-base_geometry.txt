The ``BaseGeometry`` integer validator
======================================

``BaseGeometry`` provides an ``area`` method and validates positive integer
values with ``integer_validator``.

Import and instantiate the class:

>>> BaseGeometry = __import__('7-base_geometry').BaseGeometry
>>> geometry = BaseGeometry()

Calling the validator without its required arguments raises ``TypeError``:

>>> geometry.integer_validator()
Traceback (most recent call last):
...
TypeError: BaseGeometry.integer_validator() missing 2 required positional arguments: 'name' and 'value'
>>> geometry.integer_validator("age")
Traceback (most recent call last):
...
TypeError: BaseGeometry.integer_validator() missing 1 required positional argument: 'value'

The area method raises the specified exception:

>>> geometry.area()
Traceback (most recent call last):
...
Exception: area() is not implemented

Positive integers are accepted:

>>> geometry.integer_validator("my_int", 12)
>>> geometry.integer_validator("width", 89)
>>> geometry.integer_validator("age", 1)

Non-integers raise ``TypeError`` with the field name in the message:

>>> geometry.integer_validator("name", "John")
